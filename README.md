# দৈনিক খরচের হিসাব

বাংলাদেশি টাকায় দৈনিক খরচ লিখে রাখার বাংলা অ্যাপ। কোনো অ্যাকাউন্ট বা সার্ভার লাগে না; তথ্য আপনার ব্রাউজারের LocalStorage-এ থাকে।

## চালাতে যা লাগবে

কম্পিউটারে Node.js 20.19 বা তার পরের সংস্করণ ইনস্টল থাকতে হবে।

## চালু করার নিয়ম

1. ZIP ফাইলটি Extract/Unzip করুন।
2. Terminal বা Command Prompt খুলে `daily-expense-tracker` ফোল্ডারে যান।
3. এই কমান্ডগুলো চালান:

```bash
npm install
npm run dev
```

4. Terminal-এ দেখানো ঠিকানাটি ব্রাউজারে খুলুন (সাধারণত `http://localhost:5173`)।

Production build তৈরি করতে `npm run build` চালান।

## তথ্য সংরক্ষণ

খরচের তথ্য একই ব্রাউজারের LocalStorage-এ রাখা হয়। অন্য কম্পিউটারে স্বয়ংক্রিয়ভাবে সিঙ্ক হয় না এবং এই ZIP ফাইলের মধ্যে আপনার খরচের রেকর্ড থাকে না।
